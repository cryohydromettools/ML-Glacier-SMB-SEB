# ML-Glacier-SMB-SEB

Machine Learning framework for emulating glacier **Surface Mass Balance (SMB)** and **Surface Energy Balance (SEB)** using **ERA5-Land** atmospheric data and **COSIPY** model outputs.

---

# Overview

This repository builds Machine Learning emulators capable of reproducing COSIPY simulations at a fraction of the computational cost.

The workflow consists of:

1. Preprocess COSIPY outputs
2. Preprocess ERA5-Land variables
3. Merge both datasets
4. Train Machine Learning models
5. Evaluate model performance
6. Predict SMB/SEB
7. Analyze results

# Workflow

## Step 1. Prepare COSIPY outputs

Run

```bash
python 01_preprocess_cosipy_output.py
```

or

```bash
python 01_preprocess_cosipy_output_v2.py
```

This script

- reads COSIPY simulations
- extracts SMB and SEB variables
- formats the data
- exports clean files for training

Output:

```
Processed COSIPY dataset
```

---

## Step 2. Process ERA5-Land data

Run

```bash
python 02_preprocess_geodata.py
```

This script

- reads ERA5-Land variables
- interpolates or formats data if necessary
- prepares atmospheric predictors

Typical predictors include

- Air temperature
- Relative humidity
- Wind speed
- Shortwave radiation
- Longwave radiation
- Surface pressure
- Total precipitation

Output:

```
Processed ERA5-Land predictors
```

---

## Step 3. Merge datasets

Run

```bash
python 03_merge_gla_data.py
```

This script combines

- ERA5-Land predictors
- COSIPY outputs

into a single Machine Learning dataset.

Output

```
Training dataset
```

Example

| Predictor | Target |
|------------|--------|
| ERA5-Land variables | SMB |
| ERA5-Land variables | SEB |

# Model Training

Two different Machine Learning models are available.

---

## Option A — Neural Network

Run

```bash
python 04_nn_train.py
```

The script

- splits the dataset
- trains the neural network
- validates the model
- saves trained weights

Outputs

```
Neural Network model
Training history
Metrics
```

---

## Option B — XGBoost

Run

```bash
python 04_xgb_train.py
```

or

```bash
python 04_xgb_train_v2.py
```

The script

- trains an XGBoost regression model
- performs validation
- saves the trained model

Outputs

```
XGBoost model
Feature importance
Performance metrics
```
